# P1. Prove two browser wallets can pay one seller in one transaction

Live issue: [#1](https://github.com/nefalos-tech/OneTab/issues/1)

This is the repository copy of the implementation brief. The live issue and board own status and discussion. Update both copies when the task scope changes.

Before implementation, read the [architecture](../architecture.md), [shared contracts](../contracts.md) and [development guide](../development.md).

Owner: @kyusuku
Lane: Payments
Estimated effort: 4 hours. This is a planning budget, not a delivery guarantee.
Phase: Start together

## Outcome

Two independent browser-wallet approvals produce one confirmed Devnet USDC payment to the seller.

## Start and handoffs

Start immediately in an isolated spike. Do not wait for the room API or finished screens.

Implementation prerequisites: None. Start immediately.

## Work

- [ ] Use two distinct payer wallets and a separate seller test wallet. Fund test USDC and organizer SOL, and pre-create required token accounts.
- [ ] Build one transaction, request sign-only approvals, verify both signatures against identical message bytes, merge them, and submit once.
- [ ] Record the working wallet, browser, network, mint and exact package versions. Prefer the brief's Kit direction only if this experiment proves compatibility.
- [ ] Publish the WalletBridge and signing-byte format to F2 and B1 as soon as proven. Use only test assets and keep private keys in wallets.
- [ ] At hour 2, isolate the first failing step. At hour 4, keep one supported desktop wallet type and two payers until signing works. Escalate the blocker with evidence; do not substitute backend-owned payer keys.

## Done when

- [ ] Attach the transaction explorer link and seller balance change.
- [ ] Demonstrate that the first signature alone cannot complete the payment.
- [ ] Record two separate wallet approval prompts and matching message hashes.

## File ownership

Proposed: spikes/payment-proof/ and docs/evidence/payment-proof.md. Keep its dependencies isolated from the main app until F1 integrates the proven package choices.
