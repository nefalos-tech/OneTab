## Outcome

The public desktop app uses the intended Devnet RPC and database without exposing privileged credentials.

Start hosting and environment setup in the first half of the build. Final hosted checks wait for integration.

## Work

- [ ] Choose the team's existing supported Next.js host and publish the app. Configure the Supabase project and Devnet RPC explicitly.
- [ ] Configure environment variables by name; keep secret/service-role values server-only and out of logs and source control.
- [ ] Apply reviewed schema changes and verify RLS plus grants. Block direct unauthorized writes even if the Data API is reachable.
- [ ] Check wallet-session origin/cookie settings on the real public URL.
- [ ] Verify persistence and status polling across redeploy/restart. Confirm the app does not depend on one long-running HTTP request to finish confirmation.
- [ ] Document the URL and run/deploy commands. Make no Mainnet configuration.

## Done when

- [ ] The public URL loads from another computer and the browser uses Devnet test assets.
- [ ] Anonymous/forged database mutation attempts fail.
- [ ] Create/join/Ready and an integrated payment work on the hosted environment.
- [ ] No privileged database key appears in the client bundle.
