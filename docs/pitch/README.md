# OneTab pitch deck

- [OneTab_Pitch_Deck.pdf](OneTab_Pitch_Deck.pdf) opens in the browser.
- [OneTab_Pitch_Deck.pptx](OneTab_Pitch_Deck.pptx) is the same 13 slides for PowerPoint, Keynote or Google Slides. Each slide is one picture of the PDF page, so its text can't be edited, but the Solana Explorer, demo and GitHub links still work in slide show.

Both were exported on 2026-11-08 for the Solana Hackathon. The app screens use sample data. The Devnet figures come from the payments proof run on 2026-11-07, recorded in [docs/evidence/payment-proof.md](../evidence/payment-proof.md).
